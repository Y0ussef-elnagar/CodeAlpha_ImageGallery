# 🖼️ Image Gallery Project

A simple and responsive **Image Gallery web application** built using HTML, CSS, and JavaScript.  
The project displays a grid of images and allows users to dynamically load more images with a button click.

---

## 🚀 Features

- Responsive image grid layout
- Hover animation on images
- "Load More" button to fetch more images dynamically
- Random images using Picsum API
- Mobile-friendly design

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox + Media Queries)
- JavaScript (DOM Manipulation)

---

## 📁 Project Structure

project-folder/
│
├── index.html
├── style.css
└── script.js

---

## ⚙️ How It Works

- The page initially loads 6 images from `picsum.photos`
- When the user clicks **Load More**, JavaScript generates and appends new images dynamically
- Each image is fetched using a unique random query to ensure variety
